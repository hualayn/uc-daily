# 溃结日常记录 App

溃结（溃疡性结肠炎）日常记录 Android 应用 — 每天把吃的、拉的、吃的药、身体的感受都记下来，方便回溯"症状出现前吃了什么"，也方便复诊时给医生看。

## 界面结构（四个底部 Tab）

**首页**
- 顶部：头像 + 一句每日轮播的暖心横幅（如"一定要好好吃饭！"）
- 中部：当天日期 + 一周日历条（左右滑动换周，点击选日，有排便记录的日子按活动度着色）
- 当日统计：饮食次数 / 大便次数 / 服药条数
- 四个添加入口：🍚 饮食、💩 大便、💊 服药、📝 笔记
- 下方列出当天全部记录（排便 → 感受 → 饮食 → 服药）

**耐受**
- 管理食物耐受状态：可耐受（绿）/ 谨慎（黄）/ 不耐受（红），点击状态可循环切换
- 展示每个食物被饮食记录引用（打标签）的次数，方便找出问题食物

**日历**
- 月历热力图：有排便记录的日期按活动度着绿 / 黄 / 橙 / 红色圆点
- 左右滑动翻月；点击顶部"X年X月"可快速选择年月跳转
- 点选任意日期查看当天全部记录，支持补录历史日期

**我的**
- 头像与昵称（可修改）
- 统计：记录天数 / 饮食条数 / 排便天数 / 服药条数
- 关于说明

## 功能

- **饮食记录**：早餐 / 午餐 / 晚餐 / 加餐，一天可记多条；相机拍摄或相册多选（单次最多 9 张），一条记录可加多张照片；文字备注 + 食物标签（在"耐受"页维护，记录时可多选）
- **排便记录**：每天一条，记录排便次数、夜间腹泻、大便性状（布里斯托分级 1~7）、便血、黏液、腹痛（0~10 分 + 部位）、急迫感、其他不适
- **活动度评分**：按简化 UCDAI 患者自评口径（排便次数 0~4 + 便血 0~4）自动算 0~8 分，分为缓解 / 轻度 / 中度 / 重度活动（仅供自我监测参考，不替代医生诊断）
- **服药记录**：药名（含常用药快捷选择，长按标签可删除该快捷标签）+ 剂量，一天可记多条，支持编辑 / 删除
- **今日感受**：每天一条自由文本（排便、睡眠、心情、不适…），补录历史日期同样支持
- **编辑 / 删除**：所有记录卡片均可编辑（二次确认删除）
- **全屏查看**：点照片可放大查看
- **日期回溯**：首页周历与日历页均可点选任意日期，查看 / 补录当天记录

## 技术栈

- **Kotlin** 2.2.10
- **Jetpack Compose** + Material3（底部 NavigationBar 四 Tab；记录面板为全局浮层，任何 Tab 都能打开）
- **Room** 2.7.1（本地 SQLite，数据库版本 5）
- **Coil** 2.7.0（图片加载）
- **MVVM** 架构（ViewModel + StateFlow）

## 系统要求

- Android SDK 26+（Android 8.0）
- JDK 17
- Android Studio Iguana+

## 构建

```bash

./gradlew assembleDebug
```

## 数据存储说明

- 记录存于本地 Room 数据库 `checkin_db`（表 `meal_records` 饮食、`daily_symptoms` 排便、`med_records` 服药、`daily_notes` 感受、`food_tags` 食物标签；排便 / 感受按 date 唯一）
- 照片存于应用私有目录（`getExternalFilesDir`），卸载应用时自动清理
- 相册选取的照片会复制到应用私有目录，保证卸载前一直可查看
- 数据库历史迁移：v3 删除旧版"学习打卡"数据表；v4 新增排便记录表；v5 新增服药 / 感受 / 食物标签表并为饮食记录增加标签列

## 活动度评分说明

参考 UCDAI（溃疡性结肠炎疾病活动指数）中可由患者自评的部分：

- 排便次数得分：≤4 次=0，5~6 次=1，7~10 次=2，11~14 次=3，≥15 次=4
- 便血得分：无=0，少量=1，明显=3，血块=4
- 总分 0~8：0=缓解（绿），1~3=轻度（黄），4~5=中度（橙），6~8=重度（红）

> 该评分仅供自我监测与就医参考，不能替代医生诊断。UCDAI 完整版还需医生评估（全身状况 + 病变范围）。
