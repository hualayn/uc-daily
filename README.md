# 溃结日常记录 App

饮食 + 排便症状记录 Android 应用 — 每天把吃的东西拍下来、把排便情况记下来，方便回溯"症状出现前吃了什么"。
为溃结（溃疡性结肠炎）日常管理设计：通过照片 + 文字备注回顾每一餐，通过排便记录 + 活动度评分监测病情。

## 功能

- **按餐记录**：早餐 / 午餐 / 晚餐 / 加餐，一天可记多条
- **拍照记录**：相机拍摄或从相册多选（单次最多 9 张），一条记录可加多张照片
- **文字备注**：记录吃了什么、吃完的感觉（如排便情况）
- **排便记录**：每天一条，记录排便次数、夜间腹泻、大便性状（布里斯托分级 1~7）、便血、黏液、腹痛（0~10 分 + 部位）、急迫感、其他不适
- **活动度评分**：按简化 UCDAI 患者自评口径（排便次数 0~4 + 便血 0~4）自动算 0~8 分，分为缓解 / 轻度 / 中度 / 重度活动（仅供自我监测参考，不替代医生诊断）
- **日历热力图**：有排便记录的日期按活动度着绿 / 黄 / 橙 / 红色圆点，一眼看出哪几天开始不对劲
- **日历查看**：滑动日历查看任意月份；点击顶部"X年X月"可快速选择年月跳转
- **日期回溯**：点选任意日期，查看当天饮食 + 排便记录；支持补录历史日期
- **全屏查看**：点照片可放大查看
- **编辑 / 删除**：饮食、排便记录卡片均可编辑（二次确认删除）
- **统计**：累计有记录的天数与总记录条数

## 技术栈

- **Kotlin** 2.2.10
- **Jetpack Compose** + Material3
- **Room** 2.7.1（本地 SQLite，数据库版本 4）
- **Coil** 2.7.0（图片加载）
- **MVVM** 架构（ViewModel + StateFlow）

## 系统要求

- Android SDK 26+（Android 8.0）
- JDK 17
- Android Studio Iguana+

## 构建

```bash
cd study-checkin-app
./gradlew assembleDebug
```

构建产物位于 `app/build/outputs/apk/debug/`。

## 项目结构

```
app/src/main/java/com/study/checkin/
├── MainActivity.kt        # 入口，相机/相册权限与 Activity 编排
├── ui/
│   ├── MealLogViewModel.kt  # ViewModel，状态管理、草稿、数据操作
│   └── MealLogScreen.kt     # Compose UI（日历热力图、记录卡片、添加面板、排便面板、全屏查看）
└── data/
    ├── MealRecord.kt      # 饮食记录实体 + 餐次枚举
    ├── MealRecordDao.kt   # 饮食记录 DAO
    ├── DailySymptom.kt    # 排便/症状实体 + 活动度评分（简化 UCDAI）
    ├── DailySymptomDao.kt # 排便记录 DAO
    └── AppDatabase.kt     # 数据库配置（v4，含 1→2→3→4 迁移）
```

## 数据存储说明

- 记录存于本地 Room 数据库 `checkin_db`（表 `meal_records` 饮食、`daily_symptoms` 排便，后者 date 唯一）
- 照片存于应用私有目录（`getExternalFilesDir`），卸载应用时自动清理
- 相册选取的照片会复制到应用私有目录，保证卸载前一直可查看
- 数据库 v3 迁移会删除旧版"学习打卡"数据表（改造时一次性清理）

## 活动度评分说明

参考 UCDAI（溃疡性结肠炎疾病活动指数）中可由患者自评的部分：

- 排便次数得分：≤4 次=0，5~6 次=1，7~10 次=2，11~14 次=3，≥15 次=4
- 便血得分：无=0，少量=1，明显=3，血块=4
- 总分 0~8：0=缓解（绿），1~3=轻度（黄），4~5=中度（橙），6~8=重度（红）

> 该评分仅供自我监测与就医参考，不能替代医生诊断。UCDAI 完整版还需医生评估（全身状况 + 病变范围）。
