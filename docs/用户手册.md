# 溃结日常记录软件V1.1.1 软件说明书

# 第1章 文档说明

## 1.1 手册目的

本说明书是"溃结日常记录软件V1.1.1"（以下简称"本软件"）
的软件说明书，用于说明本软件的内容、组成、设计、
功能规格、开发情况、测试结果与使用方法。
本说明书可作为软件著作权登记文档，也可作为日常使用参考。

## 1.2 适用对象

本手册面向以下人员：
1. 溃疡性结肠炎（UC）患者。
2. 患者的家属与照护者。
3. 需要使用本软件进行自我监测的用户。
4. 需要阅读用户导出数据的医生（见第21章）。

## 1.3 术语约定

| 术语 | 含义 |
| --- | --- |
| UC | 溃疡性结肠炎的英文缩写 |

| 活动度 | 病情活动程度，分四个等级 |

2. 本软件不能替代医生的诊断、治疗与随访。
3. 如病情加重或出现持续便血、发热等症状，请立即就医。
4. 用药请严格遵循医嘱，请勿自行调整剂量或停药。

# 第2章 软件概述

## 2.1 软件介绍

本软件是一款面向溃疡性结肠炎患者的安卓手机应用。
它帮助用户每天记录饮食、排便、服药和身体感受，
从而回顾"发作前吃了什么"，并在复诊时向医生展示真实数据。

本软件全部数据只保存在本机，不联网、不上传、无账号，
保护用户隐私。软件支持12种语言，可离线使用。

## 2.2 核心功能

1. 饮食记录：按餐次记录，支持拍照与相册选图，可打食物标签。
2. 排便记录：记录次数、便级、便血、腹痛等，自动计算活动度。
3. 服药记录：记录药名与剂量，一天可多次。
4. 服药提醒：设置每日提醒时刻，漏服时红点与系统通知提醒。
5. 每日感受：每天一条自由文本，记录心情、睡眠与不适。
6. 食物耐受管理：可耐受、尝试、不耐受三类管理食物。
7. 日常管理手册：饮食、生活方式、用药与心理调适等参考内容。
8. 自评量表：四题快速自评病情活动阶段。
9. 统计与导出：按日期范围导出TXT或CSV，便于医生阅读。
10. 数据恢复：通过导出的CSV文件换机或找回数据。

## 2.3 运行环境

1. 手机系统：Android 8.0（API 26）及以上版本。
2. 网络要求：无需联网，所有功能均可离线使用。
3. 账号要求：无账号，安装即可使用。
4. 存储空间：建议剩余可用空间大于500MB。
5. 照片会压缩后存入应用私有目录，占用空间有限。

## 2.4 数据隐私概述

1. 所有记录只保存在本机数据库，不出现在任何网络请求中。
2. 照片保存在应用私有目录，卸载应用后自动清除。
3. 本软件不采集、不上传任何用户个人数据。
4. 用户可随时导出全部数据，或卸载应用彻底删除。


# 第3章 软件组成

本章描述本软件的整体组成与模块划分。

## 3.1 总体组成

本软件由四个组成部分构成：

1. 界面层：用户可见的全部屏幕与交互组件。
2. 业务层：状态管理、数据操作与业务规则。
3. 数据层：本地数据库、照片存储与偏好存储。
4. 系统服务层：通知、闹钟、开机广播与更新服务。

各组成之间通过单向依赖组织，
上层依赖下层，下层不依赖上层。

## 3.2 界面层组成

界面层包含以下屏幕与组件：

| 首页 | 欢迎卡片、日历、统计卡、当天记录 |
| 耐受页 | 食物耐受三区域与标签管理 |
| 日常管理页 | 手册手风琴卡片与自评量表 |

| 全屏看图 | 照片放大查看与左右切换 |
| 首页标语页 | 标语的增删改与恢复默认 |

## 3.3 业务层组成

业务层由单一视图模型（ViewModel）承担：

1. 状态管理：以单一状态对象（MealUiState）
   集中管理界面状态，通过 StateFlow 分发。
2. 草稿管理：记录面板中的未保存草稿。
3. 数据操作：增删改查的调用与结果处理。
4. 派生计算：活动度评分、统计汇总、筛选。
5. 副作用处理：通知、提醒注册、导出与恢复。

2. 闹钟组件：精确闹钟的注册、触发与重注册。
3. 开机广播：重启后重新注册全部提醒。
4. 提醒服务：独立的协程作用域，负责提醒核对。
5. 更新组件：基于Google Play Core的应用内更新。
6. 本地化组件：语言选项、持久化与上下文包装。

# 第4章 软件设计

本章描述本软件的体系结构、关键设计与数据流。

## 4.1 体系结构

本软件采用MVVM架构，配合声明式界面：

1. 视图（View）：由Jetpack Compose声明式构建，
   全部屏幕均为不可变函数，随状态变化自动重组。
2. 视图模型（ViewModel）：单一实例持有全部界面状态，
   通过StateFlow向视图分发，隔离生命周期。
3. 模型（Model）：Room实体与Dao承担持久化，
   工具类承担照片压缩等纯函数逻辑。
4. 依赖方向：视图依赖视图模型，视图模型依赖
   数据访问对象，数据访问对象依赖数据库。

## 4.2 界面设计

1. 底部导航栏含四个标签，中央为凸起的快捷添加按钮，
   基于Material3设计规范实现。
2. 记录面板设计为全局浮层，任何标签页均可打开，
   避免用户先切换到特定页面再记录的负担。
3. 日历卡片支持周视图与整月视图两种形态，
   通过手势下滑展开、上滑收起。
4. 记录卡片统一设计：类型图标、摘要文字、
   时间戳，选中态高亮并出现操作按钮。
5. 设计系统集中管理配色、卡片、按钮、徽章等
   公共组件，保证全应用视觉一致。
6. 配色采用蓝色主题，提供浅色与深色两套。

## 4.3 状态管理设计

1. 全部界面状态集中于单一状态对象MealUiState。
2. 状态变更通过不可变拷贝产生，避免共享可变状态。
3. 视图模型用StateFlow暴露状态，视图以collect
   方式订阅，配置变化后自动恢复。
4. 记录面板的草稿独立于已保存数据，
   未保存的草稿随面板关闭而丢弃。
5. 筛选、选中、展开等交互状态均为派生状态，
   由基础状态计算得出，不单独持久化。

## 4.4 数据流设计

以"添加排便记录"为例，数据流如下：

1. 视图：用户在面板填写字段，点击保存。
2. 事件：视图模型收到保存事件，校验必填项。
3. 计算：视图模型依据当天全部排便记录
   计算活动度总分与级别。
4. 持久化：视图模型调用Dao插入新记录。
5. 回流：Room查询触发StateFlow更新。
6. 视图：日历圆点、统计卡与记录列表自动刷新。

## 4.5 本地化设计

1. 全部界面文案收敛于strings.xml资源文件，
   代码中不出现硬编码文案。
2. 列表型文案（餐次、便级、状态等）以资源ID枚举
   形式定义，随语言切换自动取对应文本。
3. AppLocale组件持有12种语言选项与持久化，
   默认跟随系统语言。
4. 应用与主界面在attachBaseContext中包装所选语言
   的上下文，保证前台界面与后台服务语言一致。
5. 语言切换通过Activity重建即时生效，无需重启应用。
6. 阿拉伯语启用从右到左布局，由清单声明支持RTL。

## 4.6 提醒机制设计

1. 用户设置的每个提醒时刻对应一个精确闹钟槽位，
   最多6个槽位。
2. 应用启动、提醒时刻变更、设备重启三种时机
   均触发闹钟的重新注册。
3. 闹钟触发后，提醒服务核对"已到点次数"与
   "当天已记录次数"，差值大于0即判定漏服。
4. 漏服时同时更新首页铃铛状态并发布系统通知。
5. 通知使用常驻红色图标与桌面角标，确保可见性。
6. 全部逻辑不依赖应用前台，后台与进程被杀场景
   由系统闹钟保证触发。

## 4.7 存储设计

1. 五张表均以日期为索引维度，支持按日查询。
2. 食物标签表保存名称、耐受状态与排序键，
   名称唯一，排序键支持拖动排序。
3. 照片不入库，仅保存文件路径引用，
   文件位于应用私有目录，卸载自动清除。
4. 偏好项均为轻量键值对，与记录数据分离。
5. 数据库版本为1，无历史迁移负担。

## 4.8 导出恢复设计

1. 导出按"日期范围×记录类型"生成文本，
   每行记录携带完整字段，便于医生阅读。
2. CSV格式同时输出食物耐受表，
   使恢复时能重建耐受清单。
3. 恢复器逐行解析本软件导出的格式，
   按"同日同内容跳过、感受按日覆盖、
   标签按名合并"三条规则写入。
4. 导出与恢复互为逆操作，保证数据可迁移。

## 4.9 更新设计

1. 采用Google Play Core的Flexible应用内更新。
2. 启动时静默检查，设置页提供手动检查入口。
3. 发现新版本后引导用户后台下载，
   下载完成后一键重启安装。
4. 侧载版本静默降级，不显示更新入口，
   保证非Play渠道用户的使用不受影响。

# 第5章 功能规格

本章逐项描述软件的功能规格，包括输入、处理与输出。

## 5.1 饮食记录功能

1. 输入：餐次（四选一）、照片（0至9张）、
   食物标签（0至多个）、备注（自由文本）。
2. 处理：按当天日期存储；新食物标签自动登记
   到耐受清单；相册照片压缩至小于300KB后
   复制到应用私有目录。
3. 输出：首页当天记录列表显示该条记录；
   统计卡的饮食计数加一；耐受页引用次数更新。
4. 约束：同一天允许多条；编辑与删除需确认。

## 5.2 排便记录功能

1. 输入：时间、布里斯托便级（1至7）、便血程度
   （四选一）、黏液、急迫感、夜间腹泻、
   腹痛评分（0至10）、疼痛部位（五选一）、
   其他不适文本。
2. 处理：按当天日期与时间存储；自动计算当天
   活动度总分（0至8）与级别。
3. 输出：日历对应日期显示彩色圆点；记录卡片
   显示活动度徽章；统计卡排便计数更新。
4. 约束：同一天允许多条，按时间排序；
   便级为必填项。

## 5.3 活动度评分功能

1. 输入：当天排便记录中的次数与最高便血程度。
2. 处理：按UCDAI自报部分计分，排便频率0至4分，
   便血0至4分，相加得总分0至8分。
3. 输出：四级结果，缓解（0分）、轻度（1至3分）、
   中度（4至5分）、重度（6至8分）。
4. 约束：仅基于自报数据，不替代医生诊断。

## 5.4 服药记录功能

1. 输入：药物名称（可快捷选择）、剂量文本、时间。
2. 处理：按当天日期存储；常用药物快捷列表
   本地保存；长按可移除快捷项。
3. 输出：首页统计更新；漏服判定输入更新。
4. 约束：同一天允许多条；编辑与删除需确认。

## 5.5 服药提醒功能

1. 输入：每日提醒次数、各提醒时刻（最多6个）。
2. 处理：为每个时刻注册精确闹钟；触发后核对
   已到点次数与已记录次数；差值大于0判定漏服。
3. 输出：首页铃铛红点；系统通知
   "您还有N次未服药，请尽快服药！"；
   红色状态栏图标与桌面角标。
4. 约束：依赖通知权限与精确闹钟权限；
   后台与重启场景由系统闹钟保证。

## 5.6 每日感受功能

1. 输入：自由文本，每日期一条。
2. 处理：按日期存储，新记录覆盖旧记录。
3. 输出：首页当天记录顶部固定显示。
4. 约束：每日期唯一；支持补录历史日期。

## 5.7 耐受管理功能

1. 输入：食物名称、初始耐受状态；
   拖动排序与跨区操作。
2. 处理：三区域（可耐受、尝试、不耐受）管理；
   点按删除；长按拖动排序或改状态；
   统计每个食物被饮食记录引用的次数。
3. 输出：耐受清单与引用次数实时展示。
4. 约束：删除食物不影响历史记录。

## 5.8 日常管理功能

1. 输入：用户的阅读与自评操作。
2. 处理：手风琴卡片展示五部分参考内容；
   自评4题（排便频率、便血、腹痛、体温）
   总分0至11分映射到四级。
3. 输出：阶段判断结果，仅参考不保存。
4. 约束：内容与第5.3节评分为两套独立量表。

## 5.9 统计功能

1. 输入：全部历史记录。
2. 处理：聚合计算记录天数、饮食次数、排便天数、
   服药次数、活动度分布、耐受分布。
3. 输出：数量块与分布展示；点开数量块进入
   年-月-日层级记录列表。
4. 约束：统计实时随记录变化。

## 5.10 导出功能

1. 输入：日期范围、记录类型（可多选）、
   格式（TXT或CSV）、保存方式（剪贴板或文件）。
2. 处理：按日期分组生成文本；CSV附食物耐受表。
3. 输出：可复制的文本或本地文件。
4. 约束：仅生成于本机，不上传。

## 5.11 恢复功能

1. 输入：本软件导出的CSV文件。
2. 处理：逐行解析，按"同日同内容跳过、
   感受按日覆盖、标签按名合并"规则写入。
3. 输出：恢复后的记录与耐受清单。
4. 约束：仅接受本软件导出的格式。

## 5.12 设置功能

1. 首页标语：增删改与恢复内置8条。
2. 主题：浅色、深色、跟随系统三选一。
3. 字体大小：多档选择，即时应用。
4. 语言：12种选项，即时切换。
5. 应用更新：静默检查与手动检查，
   下载后重启安装。
6. 关于：版本信息与简介。

## 5.13 多语言功能

1. 输入：语言选项（12种）。
2. 处理：应用级上下文包装，前台与后台统一语言。
3. 输出：界面、通知文案与渠道描述全部切换；
   阿拉伯语启用RTL布局。
4. 约束：语言资源内置，无需额外下载。

## 5.14 数据管理功能

1. 全部数据本地存储，无网络上传。
2. 卸载应用时数据库、偏好与照片自动清除。
3. 用户可通过导出功能完整迁出数据。
4. 照片压缩存储，控制占用空间。

# 第6章 开发情况

本章说明本软件的开发环境、技术选型与版本情况。

## 6.1 开发环境

| 项目 | 说明 |
| 操作系统 | Windows 11 |
| 开发工具 | Android Studio（Iguana及以后版本） |
| 构建工具 | Gradle 9.5.0 |
| 插件 | Android Gradle Plugin 9.3.0 |
| 语言 | Kotlin 2.2.10 |
| JDK | 17及以上 |
| 最低系统 | Android 8.0（API级别26） |

## 6.2 技术选型

| 类别 | 选型 | 用途 |
| 界面 | Jetpack Compose | 声明式UI构建 |
| 组件 | Material3 | 设计组件与导航栏 |
| 数据库 | Room 2.7.1 | 本地结构化存储 |
| 图片 | Coil 2.7.0 | 照片加载与显示 |
| 架构 | MVVM + StateFlow | 状态管理与数据流 |
| 更新 | Google Play Core 2.1.0 | 应用内更新 |

## 6.3 开发过程说明

1. 需求分析：确定面向UC患者的核心记录场景，
   明确饮食、排便、服药、感受四类记录。
2. 原型设计：确定四标签页与中央快捷添加的
   信息架构，绘制界面原型。
3. 数据建模：设计五张表与食物标签的关联方式，
   确定活动度评分算法。
4. 界面开发：基于Compose实现全部屏幕与组件，
   沉淀设计系统。
5. 功能开发：逐项实现记录、提醒、耐受、
   统计、导出恢复与多语言功能。
6. 测试与修正：按第7章的测试项逐功能验证，
   修正发现的问题。
7. 发布准备：构建签名包，配置多语言分发
   与应用内更新。

# 第8章 安装与首次使用

## 8.1 安装软件

1. 方式一：在Google Play中搜索"UC Daily"并安装。
2. 方式二：下载安装包（APK）后，在手机上点击安装。
3. 首次安装侧载版本时，需允许"安装未知来源应用"。
4. 安装完成后，点击桌面图标进入软件。

## 8.2 软件申请的权限

| 权限 | 用途 | 拒绝后的影响 |
| --- | --- | --- |
| 相机 | 拍摄饮食照片 | 只能从相册选择照片 |
| 相册 | 选择饮食照片 | 只能拍照 |
| 通知 | 服药提醒通知 | 无法收到提醒通知 |
| 精确闹钟 | 准点触发服药提醒 | 提醒可能延迟或失效 |

1. 权限均为可选，按需授予即可正常使用基本功能。
2. 通知与精确闹钟权限影响服药提醒，建议授予。
3. Android 13及以上系统首次使用提醒功能时会弹出授权。

## 8.3 首次启动

1. 首次启动时，软件语言默认跟随手机系统语言。
2. 首页显示欢迎卡片、日历与当天记录区域。
3. 底部有四个标签页：首页、耐受、日常管理、我的。
4. 中间凸起的"+"按钮用于快速添加记录。

## 8.4 快速上手五步

1. 点击"+"选择"饮食"，记录今天的第一顿饭并拍照。
2. 点击"+"选择"便便"，记录一次排便并选择便级。
3. 点击"+"选择"服药"，记录一次服药。
4. 进入"我的-服药设置"，设置每日提醒次数与时刻。
5. 查看首页日历，有排便记录的日期会显示彩色圆点。

# 第9章 界面总览

## 9.1 底部导航

1. 首页：日历、每日统计与当天记录。
2. 耐受：食物耐受状态管理。
3. 日常管理：管理手册与自评量表。
4. 我的：统计、设置与数据管理。
5. 点击标签即可切换，各页面相互独立。

## 9.2 快捷添加按钮

1. 底部导航中央有一个凸起的"+"按钮。
2. 在任意标签页点击它，都会弹出"添加记录"面板。
3. 面板提供四种记录：饮食、便便、服药、感受。
4. 选择任意一种，即可在当前日期下添加记录。

## 9.3 记录面板

1. 记录面板是全局浮层，覆盖在当前页面上方。
2. 在首页点选历史日期后打开面板，即为补录该日。
3. 面板顶部显示"记录到"的日期，补录时带"（补录）"。
4. 填写完成后点击"保存记录"，记录即写入所选日期。

# 第10章 首页

首页是软件的默认页面，集中展示当天的记录与日历。

## 10.1 欢迎卡片

欢迎卡片位于首页顶部，包含以下内容：

1. 头像：显示当前用户头像，点击可进入"我的"页面。
2. 问候语：按当前时间显示"早上好"至"夜深了"等问候。
3. 每日标语：轮播显示一句鼓励语，标语列表可在
   "我的→设置→首页标语"中编辑、添加或删除。

## 10.2 服药提醒铃铛

欢迎卡片右上角有一个铃铛图标，用于提示服药：

1. 当天还有未记录的到点服药时间时，铃铛显示红点。
2. 点击铃铛会跳回今天，并打开"添加服药"面板。
3. 到点未记录时，系统同时发送红色通知。
4. 当天所有到点服药均已记录时，铃铛不显示红点。

## 10.3 日历

日历卡片显示日期，并有周视图与整月视图两种形态。

### 10.3.1 周视图（默认）

1. 显示当前一周的七天，每格显示日期与星期。
2. 点击左右箭头或左右滑动，切换到上一周或下一周。
3. 点击某一天，可切换查看或补录该天的记录。
4. 有排便记录的日期，按当天活动度显示彩色圆点：
   绿色为缓解，黄色为轻度，橙色为中度，红色为重度。

### 10.3.2 整月视图

1. 在日历卡片上向下拖动，可展开整月视图。
2. 向上拖动或使用箭头，可收起回周视图或切换月份。
3. 整月视图中，同样可用彩色圆点标记有排便记录的日期。
4. 整月视图顶部显示"某年某月"，便于回看历史。

## 10.4 每日统计卡

日历下方显示所选日期的三类统计：

1. 饮食：当天的饮食记录条数。
2. 排便：当天的排便记录次数。
3. 服药：当天的服药记录条数。

点击某一统计卡，可筛选出该天该类型的记录列表；
再次点击该统计卡，或点击"重置"，可清除筛选条件。

## 10.5 当天记录

页面下方显示所选日期的全部记录，按时间先后混排：

1. 便便、饮食、服药记录按记录时间排序。
2. 当天的"感受"（每日笔记）固定显示在最上方。
3. 在首页点击某张记录卡片，卡片被选中（单选）。
4. 选中后卡片上出现"编辑"与"删除"按钮。
5. 点击"删除"会弹出确认框，确认后删除该条记录。
6. 点击任意历史日期，可以查看或补录该天的记录。

# 第11章 饮食记录

饮食记录用于记录每一餐吃了什么，是耐受管理的数据来源。

## 11.1 添加饮食记录

在任意标签页点击底部中央的"+"按钮，选择"饮食"，
打开添加饮食面板，按以下步骤操作：

1. 选择餐次：早餐、午餐、晚餐或加餐。
2. 添加照片：点击"拍照"或"从相册"选择照片。
3. 添加食物标签：从耐受列表中选择本次吃到的食物。
4. 填写备注：可写烹饪方式、吃完的感觉等。
5. 确认记录日期：补录时先选择目标日期。
6. 点击"保存记录"，完成本次饮食记录。

## 11.2 餐次

每次饮食记录对应一个餐次，共四种：

1. 早餐：早上的正餐。
2. 午餐：中午的正餐。
3. 晚餐：晚上的正餐。
4. 加餐：正餐之间加吃的零食或水果。

同一天可以记录多条饮食，餐次可以重复。

## 11.3 照片

1. 点击"拍照"调用相机拍摄，首次使用需授予相机权限。
2. 点击"从相册"可选择多张照片，一次最多选择9张。
3. 从相册选择的照片会被压缩为小于300KB的JPEG格式。
4. 压缩后的照片存入应用私有目录，卸载应用时自动清除。
5. 每条饮食记录可以包含多张照片。
6. 待保存的照片在保存前可以逐张移除。

## 11.4 食物标签

1. 食物标签在"耐受"标签页中统一维护。
2. 添加饮食时，可为本次吃到的食物勾选多个标签。
3. 勾选新食物时，可先选择它的初始耐受状态。
4. 标签帮助回顾：发作前吃了哪些食物。

## 11.5 备注

备注为自由文本，建议记录：

1. 烹饪方式，如煎、炒、煮、烤。
2. 吃完后的感受，如腹胀、不适、无异常。
3. 其他想留存的说明。

## 11.6 全屏查看照片

1. 点击记录卡片上的任意照片，进入全屏查看。
2. 左右滑动可在同一记录的多张照片间切换。
3. 点击空白区域或返回键，退出全屏查看。

## 11.7 编辑与删除

1. 选中记录卡片后，点击"编辑"可修改该条记录。
2. 编辑时各字段均可修改，包括照片与标签。
3. 点击"删除"会弹出确认，确认后删除该条记录。
4. 删除记录不会从设备中删除原始照片文件。
5. 历史记录同样支持编辑与删除。

# 第12章 排便记录

排便记录是病情活动度评分的主要数据来源。

## 12.1 添加排便记录

点击"+"按钮，选择"便便"，打开排便记录面板：

1. 选择记录日期，补录历史日期时先选日期。
2. 填写时间：补录时可将时间调整为实际时间。
3. 选择布里斯托便级：1至7级，见12.2节对照表。
4. 选择便血程度：无、少量、明显、血块。
5. 选择黏液：有或无。
6. 选择急迫感：有或无。
7. 选择夜间腹泻：有或无。
8. 填写腹痛：0至10分评分，并选择疼痛部位。
9. 可填写其他不适的文字说明。
10. 点击"保存记录"，完成本次排便记录。

## 12.2 布里斯托便级对照表

布里斯托便级（Bristol Stool Scale）用于描述大便性状：

| 级别 | 名称 | 描述 |
| 1 | 硬块 | 分离的硬块，排便困难 |
| 2 | 块状香肠 | 块状香肠状，表面凹凸 |
| 3 | 带裂纹香肠 | 香肠状，表面有裂纹 |
| 4 | 光滑香肠 | 光滑柔软的香肠状，理想性状 |
| 5 | 软块 | 柔软的软块，边缘清晰 |
| 6 | 糊状 | 糊状，边缘模糊，有块状碎片 |
| 7 | 水样 | 水样，无固体块，完全液体 |

## 12.3 便血程度

便血程度共四个选项：

1. 无：大便中未见血液。
2. 少量：表面少量血丝。
3. 明显：肉眼可见明显血液。
4. 血块：出现血块。

便血程度会直接参与活动度评分计算。

## 12.4 腹痛

腹痛记录包含评分与部位两部分：

1. 评分：0至10分，0为不痛，10为最痛。
2. 部位：无、右下腹、左下腹、脐周、全腹。
3. 评分与部位共同帮助医生判断疼痛情况。

## 12.5 其他字段

1. 黏液：记录大便中是否有黏液。
2. 急迫感：记录是否有突然的强烈便意。
3. 夜间腹泻：记录夜间是否有腹泻。
4. 其他不适：自由文本，记录上述未覆盖的情况。

## 12.6 多条记录与补录

1. 同一天可以记录多次排便，逐条录入。
2. 多条记录按时间先后排序显示。
3. 点击首页日历中的任意历史日期，可补录该天记录。
4. 补录时可以把时间字段调整为实际的排便时间。

# 第13章 病情活动度评分

软件根据排便记录自动计算病情活动度，用于日常自我监测。

## 13.1 评分原理

评分基于溃疡性结肠炎疾病活动指数（UCDAI）中可由
患者自我报告的部分，取"排便频率"与"便血"两个维度，
自动计算每日总分，无需人工填写。

## 13.2 排便频率评分

按当天排便次数计分：

| 排便次数（次/日） | 得分 |
| 4次及以下 | 0分 |
| 5至6次 | 1分 |
| 7至10次 | 2分 |
| 11至14次 | 3分 |
| 15次及以上 | 4分 |

## 13.3 便血评分

按当天排便中最高便血程度计分：

| 便血程度 | 得分 |
| 无 | 0分 |
| 少量 | 1分 |
| 明显 | 3分 |
| 血块 | 4分 |

## 13.4 总分分级

两项得分相加，总分0至8分，分为四级：

| 总分 | 级别 | 颜色 |
| 0分 | 缓解 | 绿色 |
| 1至3分 | 轻度活动 | 黄色 |
| 4至5分 | 中度活动 | 橙色 |
| 6至8分 | 重度活动 | 红色 |

## 13.5 评分用途

1. 首页日历中，有排便记录的日期显示对应颜色圆点。
2. 排便记录卡片上显示当天活动度级别与分数。
3. 统计页可查看全部记录的活动度分布。
4. 便于回顾：发作前几天的分数变化一目了然。

## 13.6 注意事项

1. 本评分仅用于自我监测与就医参考，不替代医生诊断。
2. 完整的UCDAI还包含全身状况与病变范围评估，
   需要由医生完成，本软件只覆盖自报部分。
3. 如分数持续升高或出现重度活动，请及时就医。
4. 请勿与"日常管理"页的自评4题分数混用，

# 第14章 服药记录与提醒

4. 确认记录日期；补录时先选择目标日期。
5. 点击"保存记录"，完成本次服药记录。
6. 同一天可以记录多次服药。
7. 已有记录可以编辑或删除（删除需确认）。

## 14.2 常用药物

1. 常用药物是用户自定义的快捷药物列表。

## 14.3 设置服药提醒

进入"我的→服药设置"，按以下步骤设置提醒：

1. 设置每日提醒次数，即每天应服药的总次数。
2. 为每个提醒时刻选择具体时间，最多6个时刻。
3. 保存后，首页铃铛与系统通知即按设置工作。
4. 可随时修改次数与时刻，修改后立即生效。
5. 首次设置时，若系统未授予通知权限，
   软件会引导用户前往系统设置授予。

   服药设置页提供权限状态卡片，点按可前往授予。

## 14.4 漏服判定

软件按以下规则判断是否漏服：

1. 到点的提醒次数，大于当天已记录的服药次数时，
   视为存在漏服。
2. 例如设了2次提醒且均已到点，只记录了1次服药，
   则提示"还有1次未服药"。
3. 记录足够次数后，红点与通知自动消失。

## 14.5 漏服提示

存在漏服时，软件同时给出两种提示：

1. 首页铃铛显示红点，点击可直接打开添加服药面板。
2. 系统通知栏出现红色通知，文字为
   "您还有N次未服药，请尽快服药！"，
   并显示红色常驻状态栏图标或桌面角标。

## 14.6 提醒机制说明

1. 提醒使用系统精确闹钟触发，准点触发。
2. 应用在后台运行或被系统杀死时，提醒仍会触发。
3. 设备重启后，软件会重新注册全部提醒时刻。
4. 应用每次启动时也会核对并补注册提醒。
5. 若取消通知权限，铃铛红点仍有效，但无系统通知。

## 14.7 权限要求

1. Android 13及以上：需授予"通知"权限。
2. Android 12及以上：需授予"精确闹钟"权限。
3. 拒绝权限不影响记录功能，仅影响提醒与通知。

# 第16章 耐受管理

耐受页帮助建立"能吃什么、要尝试什么、要避开什么"的清单。

## 16.1 耐受状态

食物按耐受状态分为三个区域：

1. 可耐受（绿色）：可以正常吃的食物。
2. 尝试（黄色）：不确定，需谨慎尝试的食物。
3. 不耐受（红色）：应尽量避免的食物。

## 16.2 新增食物

1. 食物主要通过"添加饮食"面板新增。
2. 勾选新食物时，先选择它的初始耐受状态。
3. 新增的食物立即出现在对应状态区域。
4. 也可在记录历史饮食时补充新食物。

## 16.3 排序与改状态

1. 长按某个食物标签（按住约400毫秒）开始拖动。
2. 在同一区域内释放：调整该区域内的排序。
3. 拖到另一个区域释放：改变该食物的耐受状态。
4. 拖动过程中区域会高亮提示释放位置。
5. 排序与状态变化即时保存。

## 16.4 删除食物

1. 点按食物标签，标签上出现"X"角标。
2. 点击"X"，该食物从清单中删除。
3. 删除食物不影响已有的饮食记录与统计。

## 16.5 引用次数

1. 每个食物标签显示被多少条饮食记录引用。
2. 引用次数多的"不耐受"食物，往往就是问题食物。
3. 结合引用次数与发作时间，可定位诱因。

## 16.6 使用建议

1. 记录每一餐时尽量勾选全部吃到的食物。
2. 感觉某食物可能诱发不适时，放入"尝试"区观察。
3. 连续多次出现不适的食物，移入"不耐受"区。
4. 缓解期可尝试将"不耐受"食物移回"尝试"区，
   小量试探并记录反应。
5. 回顾发作前的几天记录，核对当时吃到的食物。

# 第21章 记录导出与恢复

## 21.1 导出记录

   饮食、服药、排便、感受（可多选）。

# 第23章 常见问题

## 23.1 收不到服药提醒通知怎么办？

1. 检查系统"设置→通知"中是否允许本软件通知。
2. Android 12及以上检查"精确闹钟"权限是否授予。
3. 确认提醒时刻已设置且已保存。
4. 关闭省电模式对后台的限制，避免闹钟被拦截。

## 23.2 提醒没有准点触发？

1. 授予"精确闹钟"权限（Android 12及以上必需）。
2. 重启应用一次，提醒会重新注册。
3. 避免在系统设置中关闭本软件的闹钟权限。

## 23.3 照片不见了？

1. 照片保存在应用私有目录，卸载应用即清除。
2. 换机前请先导出记录，或自行备份照片。
3. 删除某条饮食记录，不会删除设备中的原始照片。

## 23.4 删除记录会删除照片吗？

1. 不会。删除记录只删除数据库中的条目。
2. 设备相册中的原始照片保持不变。
3. 应用私有目录中的压缩照片，随卸载清除。

## 23.5 两种评分有什么区别？

1. 第13章评分：基于UCDAI的0至8分，自动计算，
   用于日历圆点与记录卡片。
2. 第17章自评：4题共0至11分，手动作答，
   用于快速阶段判断。
3. 两者独立，数值不能互相比较。

## 23.6 如何回看发作前吃了什么？

1. 打开首页日历，找到发作开始的日期。
2. 向左滑动查看前几天的日期。
3. 逐日查看饮食记录与食物标签。

## 23.7 如何补录历史日期的记录？

1. 点击首页日历中的任意历史日期。
2. 点击"+"选择记录类型。
3. 面板顶部显示该日期并带"（补录）"标记。
4. 排便记录可把时间调整为实际时间。

## 23.8 如何更换软件语言？

2. 选择目标语言，立即生效。
3. 选择"跟随系统"则随手机语言变化。

## 23.9 应用内更新没有反应？

1. 应用内更新仅对Google Play安装的版本有效。

## 24.1 名词解释

1. 溃疡性结肠炎（UC）：一种慢性炎症性肠病，
   主要累及结肠与直肠，表现为腹泻、便血、腹痛。
2. UCDAI：溃疡性结肠炎疾病活动指数，
   由排便频率、便血、医生评估、全身状况四部分组成。
3. 布里斯托便级：国际通用的粪便性状1至7级分类。
4. 缓解期：症状消失或明显减轻、病情稳定的阶段。
5. 发作（flare）：症状加重、病情活动加重的阶段。
6. 少渣饮食：低纤维、易消化的饮食方式。
7. 黏液便：大便中带有黏液，常见于肠黏膜炎症。
8. 急迫感：突然而强烈的便意，难以立即控制。

## 24.6 记录字段速查

四类记录的字段速查如下：

| 记录类型 | 字段 |
| 饮食 | 餐次、照片、食物标签、备注 |
| 排便 | 时间、便级、便血程度、黏液、急迫感、夜间腹泻 |
| 排便（续） | 腹痛评分、疼痛部位、其他不适 |
| 服药 | 药物名称、剂量、时间 |
| 感受 | 自由文本内容 |

1. 饮食、排便、服药每天均允许多条记录。
2. 感受每日期唯一，新记录覆盖旧记录。
3. 排便与服药的时间字段可补录调整。
4. 布里斯托便级共7级，详见24.2节。
5. 药物名称可从常用药物快捷填入。
6. 食物标签在耐受页统一维护。
7. CSV导出每行携带该记录的全部字段。
